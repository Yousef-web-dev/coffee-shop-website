# ☕ Coffee Shop Website

A website for browsing and ordering the café's beverages and desserts, featuring a modern, responsive design compatible with all screens.

---

## 🌟 Features

- 📱 Fully responsive design compatible with mobile, tablet, and desktop.
- ☕ Attractive display of the food and beverage menu.
- 🎨 Clean and smooth user interface.
- ⚡ Interactive interface controls powered by JavaScript.

---

## 🛠️ Tech Stack

- **HTML5** - To build the website structure.
- **CSS3** - For styling, colors, and dimensions.
- **JavaScript** - To add interactivity to the page.
